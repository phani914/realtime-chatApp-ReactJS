# Realtime Chat App ReactJS

A responsive React chat app UI built with Vite. It includes a themed landing hero, navbar, sidebar, summary cards, and a chat window scaffold ready for realtime socket and API integration.

## Scripts

```bash
npm install
npm run dev
npm run build
```
